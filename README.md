# Simple Calculator Using C

## About the Project

This project is a simple menu-driven calculator developed using the C programming language.

The calculator performs basic arithmetic operations such as:

- Addition
- Subtraction
- Multiplication
- Division

It also handles division by zero and invalid menu choices.

## Features

1. Addition
2. Subtraction
3. Multiplication
4. Division
5. Exit option
6. Division by zero handling
7. Invalid choice handling

## Technologies Used

- C Programming Language
- Standard Input/Output Library

## C Concepts Used

- Variables
- Data types
- printf()
- scanf()
- if-else
- switch-case
- do-while loop
- Arithmetic operators

## How to Run

1. Download or clone the repository.
2. Open `main.c` in a C compiler.
3. Compile the program.
4. Run the program.
5. Select an operation from the menu.
